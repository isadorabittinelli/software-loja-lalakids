<h2>Software Lalá Kids</h2>

<h3>🔎 Objetivo</h3>
• Software desenvolvido para a loja de produtos infantis e infantojuvenis Lalá Kids para que a dona possa realizar o controle de estoque de forma automática e abandonar as planilhas de Excel onde acontecia diversos erros (causados pelo cadastro manual)
<br>
• Idealizado em grupo com o intuito de aperfeiçoar o que foi aprendido na disciplina de Programação Orientada a Objetos durante a faculdade de ADS
<br><br>
<h3>⌨️ Tecnologias utilizadas</h3>
HTML | C#
